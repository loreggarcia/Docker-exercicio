# Método 5C
Contextualizar define requisito e contrato. Consultar delimita uma pergunta e identifica fonte. Confrontar compara a hipótese com código, documentação ou execução. Construir aplica uma decisão explicável. Comprovar coleta sucesso e erro e relaciona resultados ao requisito.

> Uma resposta de IA é uma hipótese técnica. Ela deve ser confrontada com documentação, código ou execução antes de ser aceita.

Preencha o [template](../templates/registro-5c-template.md) com palavras próprias. Inclua decisões rejeitadas e resultados inesperados. Saída observada vale mais que uma expectativa escrita como fato. O [roteiro de documentação](../templates/activity-readme-prompts.md) contém perguntas, sem respostas prontas.
